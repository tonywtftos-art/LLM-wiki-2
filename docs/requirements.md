# 需求摘要

> 依「先討論、後生成」：先由 AI 訪談使用者、整理需求，確認後才建立 wiki 內容。

## 訪談紀錄（2026-11-18）

| # | 問題 | 使用者回答 |
|---|---|---|
| 1 | 主題範圍 | 沿用「象徵 vs 實質永續作為」的概念；只用這次指定的文獻（約 6 篇），不沿用 RA 全部文本 |
| 2 | 簡報觀眾 | 修課同學，非商管背景 |
| 3 | 資料來源 | 使用者之後一篇一篇提供 |
| 4 | 存放位置 | 新資料夾＋新 GitHub repo，上次的作業保留不動 |
| 5 | Ingest 方式 | AI 直接寫完，使用者事後審 |
| 6 | 簡報形式 | 12–15 頁 HTML，含小測驗 |
| 7 | 必做檢查 | 引文和頁碼對照原文；簡報每頁可追溯到 wiki；非商管背景聽得懂；文獻之間的矛盾要標出 |
| 8 | 上傳方式 | GitHub 網頁拖曳；PDF 不上傳 |

## 確認的需求

1. **主題**：企業的永續作為，哪些是「說到」（象徵），哪些是「做到」（實質）。
2. **Wiki**：ingest 6 篇（至少 5 篇），每篇都有文獻頁，並整合進概念頁。
3. **簡報**：讓不懂商管的人看完能說出「象徵和實質差在哪」，並能判斷簡單的例句。
4. **知識來源限制**：簡報只能使用 wiki 內的內容；wiki 只能使用 raw/ 原文。
5. **檢查**：上面 4 項檢查都要做，每次執行都留下檢查報告（checks/）。
6. **著作權**：PDF 不進 GitHub，頁面只引用短句並附頁碼。
